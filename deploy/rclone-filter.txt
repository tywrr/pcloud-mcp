# What rclone hides from Claude when it serves the whole pCloud Drive (~/pCloudDrive). Hidden
# files and folders are gone from listings, searches and reads alike. Install it next to
# webdav.env and point rclone at it there (docs/setup.md, "Serving the whole drive"):
#
#   cp deploy/rclone-filter.txt ~/.config/chance-of-files/rclone-filter.txt
#   echo "RCLONE_FILTER_FROM=$HOME/.config/chance-of-files/rclone-filter.txt" >> ~/.config/chance-of-files/webdav.env
#   systemctl --user restart chance-of-files-webdav
#
# One rule per line. "- pattern" hides what matches. A pattern that starts with "/" is anchored
# at the root of the served folder; one without matches a name in any folder. "/**" at the end
# hides a folder with everything in it. Lines starting with "#" are comments, and a comment
# can't follow a rule on the same line (it would become part of the pattern). Full syntax:
# https://rclone.org/filtering/

# pCloud's client-side encrypted folder. While it is unlocked, pCloud Drive shows its files in
# plain text like any others, so without this rule Claude could read them.
- /Crypto Folder/**

# Desktop trash folders (Linux), and folder settings that macOS and KDE leave everywhere.
- /.Trash-*/**
- .DS_Store
- .directory

# pCloud Drive's icon file at the root of the drive.
- /.pcloudicon.png

# - /Taxes/**
